# Workshop Activities

The second half of the workshop is a hands on exercise with a range of materials from the Endangered Archives Programme. 
We hope that participants will leave the workshop with the code and experience needed to process materials for their own research. 

We encourage you to form pairs and work together. 

a. Locate a relevant collection
- Identify a collection in the EAP that you would like to process: https://eap.bl.uk/search
- Find a file that you would like to process and locate the IIIF manifest URL. For example: https://eap.bl.uk/archive-file/EAP931-1-5-6  

b. Download a sample of the image files  
- Open the "Download images for processing" notebook: [![](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1zzhPqijgavn3m4fpqQo3Htgg4AdQglWX?usp=sharing)


- Replace the manifest_url with your File's address. 
- Run all cells in the notebook, so that you have your images saved in Drive. 
- If the images are too small to read, you can download a larger version using this notebook. [![](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1Fwi6BjSf6MvGTWkPS_pUvHdEpw0zEvuv?usp=sharing)

c. Process the images and metadata
- Open the "Processing workflows" notebook: [![](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1-wksvuqBUv8qq2mLJ8EbbluStjyvXIp7?usp=sharing)  
- Run all cells in the notebook until your have an output.json file saved in Drive. 

d. Publish your data as a spreadsheet or static website
- Open the "Saving and Publishing" notebook: [![](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1graycCkEiGLwMlFIoZg3-eDAXH5cKYkP?usp=sharing)  
- Once complete, you will have a file in Drive that you can open in Google Sheets.
